# Security policy

## Supported versions

Only the latest release of `giskard-actions` receives security fixes. Pin the full commit SHA of the latest release and let Renovate (or a similar tool) keep it current.

## Reporting a vulnerability

Do not open a public issue or pull request for security problems.

Report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/Giskard-AI/giskard-actions/security/advisories/new) for this repository (**Security** tab, then **Report a vulnerability**). Include:

- the affected action or workflow and the release or commit SHA,
- a description of the issue and its impact,
- steps or a minimal workflow to reproduce it.

We acknowledge reports as quickly as we can, keep you informed while we investigate, and credit you in the published advisory unless you prefer otherwise.
